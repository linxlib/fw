# astp 结构设计

> 本文档已按**本项目（`github.com/linxlib/fw/v2`）的 `astp` 包**重写。
> 早先版本描述的是外部旧版 `astp` 库（`File` / `Struct` / `Function` / `Receiver` /
> `TypeParam` / `AttrType` / `AT_POST` / `elemType` / PascalCase JSON key 等模型），
> 与当前仓库内的扁平单包 `astp/` 已不对应。当前类型模型以 `astp/types.go` 为准，
> JSON key 为 snake_case。

## 总览

```
Project
└── Packages map[pkgPath]*Package
    ├── Types     map[name]*Type     // struct / interface / alias / basic / slice / map / pointer / func / enum
    ├── Functions map[name]*Func     // 自由函数（方法在所属 Type.Methods 上）
    ├── Variables map[name]*Var
    ├── Constants map[name]*Const
    └── Enums     map[name]*Enum
```

解析入口 `astp/parser.go`，产物由 `astp/generator.go` 序列化为 `.astp.json`，
由 `astp/loader.go` 读回，`astp/query.go` 提供查询。

**设计要点**

- 文件（`ast.File`）不是一等公民：`parseFile` 把声明直接摊平进所属 `Package`，
  所以模型里没有 `File` 节点，也没有 `keyHash` / `index`（源码序）之类的字段。
- 注解（`@GET`、`@Service` ...）不是枚举表，而是**按名字自由解析**的
  `Annotation{Name, Raw, Args, KV}`，由中间件/插件自行约定。
- 类型之间只存 `TypeRef`（引用），不内联展开，避免循环引用。

## TypeKind

```go
type TypeKind string

const (
    KindStruct    TypeKind = "struct"
    KindInterface TypeKind = "interface"
    KindAlias     TypeKind = "alias"
    KindBasic     TypeKind = "basic"
    KindSlice     TypeKind = "slice"
    KindMap       TypeKind = "map"
    KindPointer   TypeKind = "pointer"
    KindFunc      TypeKind = "func"
    KindEnum      TypeKind = "enum"
    KindTypeParam TypeKind = "typeparam" // Go 1.27 泛型支持新增：这是一个类型参数，不是具名类型
)
```

`Kind` 描述的是 `TypeRef` **最外层**的类型形状，例如 `*Stack[T]` 是 `kind: "pointer"`，
`[]T` 是 `kind: "slice"`。

## 注释 / 注解

`CommentGroup` 同时保留原始注释行与解析出的注解：

```json
{
    "list": [
        { "text": "Push 泛型方法" },
        { "text": "@POST" }
    ],
    "annotations": ["POST"],
    "parsed_annotations": [
        { "name": "POST", "raw": "@POST" }
    ]
}
```

支持的注解写法：

```go
// @X
// @X value
// @X(a,b)
// @X(k=v, role=admin)
```

## Type

```go
type Type struct {
    Name       string        // 类型名
    PkgPath    string        // 包路径
    Kind       TypeKind      // struct, interface, alias, enum 等
    Fields     []*Field      // 结构体字段
    Methods    []*Func       // 方法（接口则为其方法集）
    Embedded   []*TypeRef    // 嵌入字段（保留字段，当前解析未填充）
    Implements []string      // 实现的接口名（保留字段，当前解析未填充）
    Generic    *GenericSpec  // 该类型自身声明的类型参数，如 Stack[T any] 的 T
    AliasOf    *TypeRef      // alias 指向的目标
    KeyType    *TypeRef      // map 的键类型
    ElemType   *TypeRef      // slice / map / pointer 的元素类型
    Doc        *CommentGroup
}
```

```json
{
    "name": "Stack",
    "pkg_path": "astp/testdata",
    "kind": "struct",
    "fields": [
        { "name": "items", "type": { "kind": "slice", "elem_type": { "name": "T", "kind": "struct" } } }
    ],
    "methods": [ ... ],
    "generic": { "params": [ { "name": "T", "constraints": [ { "name": "any", "kind": "struct" } ] } ] }
}
```

## Field

```go
type Field struct {
    Name     string
    Type     *TypeRef
    Tag      map[string]string // 解析后的 struct tag
    Doc      *CommentGroup
    Embedded bool              // 匿名嵌入字段
}
```

```json
{
    "name": "items",
    "type": { "kind": "slice", "elem_type": { "name": "T", "kind": "struct" } },
    "embedded": false
}
```

> 注：`Type.Fields` 中的类型参数引用**当前仍标记为 `kind: "struct"`**
> （只有函数/方法签名内的类型参数会被标记为 `kind: "typeparam"`），
> 字段侧统一标记是后续项。

## Func（函数 / 方法）

函数与方法共用同一个结构，用 `Recv` 是否为 nil 区分：

```go
type Func struct {
    Name       string
    PkgPath    string
    Recv       *TypeRef     // 接收者；nil 表示自由函数
    Params     []*Param
    Results    []*Param
    Generic    *GenericSpec // 该函数/方法【自身声明】的类型参数
    Doc        *CommentGroup
    Signatures []string     // 保留字段，当前解析未填充
}
```

```json
{
    "name": "GetName",
    "pkg_path": "astp/testdata",
    "recv": { "name": "User", "kind": "pointer" },
    "results": [ { "name": "", "type": { "name": "string", "kind": "basic" } } ]
}
```

### Go 1.27 方法泛型（generic methods）

方法可以声明自身的类型参数（如 `Push[V any]`）。一个方法同时拥有**两类**类型参数，
存储位置不同，互不混淆：

| 类别 | 例 | 存储位置 | JSON key |
| --- | --- | --- | --- |
| 接收器类型实参 | `*Stack[T]` 中的 `T` | `Func.Recv.Generic`（`*GenericArg`） | `recv.generic.args` |
| 方法自身类型参数 | `Push[V any]` 中的 `V` | `Func.Generic`（`*GenericSpec`） | `generic.params` |

- `Func.Generic` **仅当该方法自身声明了类型参数时**才非 nil。
  接收器是泛型但方法自身没有类型参数（如 `Pop`）时，`Generic` 保持 `null`。
- 方法自身类型参数在静态分析阶段作为「已声明占位」保留：具体类型只在调用点可知，
  astp 不做实例化替换，也不推断调用点实参。
- 签名内直接以类型参数为类型的 `Param.Type` 会被标记为 `kind: "typeparam"`
  （详见下文 TypeRef）。

带自身类型参数的方法：

```go
// Push 泛型方法
// @POST
func (s *Stack[T]) Push[V any](v V) {}
```

```json
{
    "name": "Push",
    "pkg_path": "astp/testdata",
    "recv": {
        "name": "Stack",
        "kind": "pointer",
        "generic": {
            "args": [ { "name": "T", "kind": "typeparam" } ]
        }
    },
    "params": [
        { "name": "v", "type": { "name": "V", "kind": "typeparam" } }
    ],
    "results": [],
    "generic": {
        "params": [
            { "name": "V", "constraints": [ { "name": "any", "kind": "struct" } ] }
        ]
    },
    "doc": {
        "list": [ { "text": "Push 泛型方法" }, { "text": "@POST" } ],
        "annotations": [ "POST" ]
    }
}
```

仅使用接收器类型参数的方法（`Generic` 为 null，返回值 T 被标记为类型参数）：

```go
// @GET
func (s *Stack[T]) Pop() T { return s.items[0] }
```

```json
{
    "name": "Pop",
    "pkg_path": "astp/testdata",
    "recv": {
        "name": "Stack",
        "kind": "pointer",
        "generic": { "args": [ { "name": "T", "kind": "typeparam" } ] }
    },
    "results": [ { "name": "", "type": { "name": "T", "kind": "typeparam" } } ]
}
```

方法自身类型参数的约束引用结构类型参数：

```go
// @GET
func (s *Stack[T]) Wrap[U ~T](u U) U { return u }
```

```json
"generic": {
    "params": [
        { "name": "U", "constraints": [ { "name": "T", "kind": "struct" } ] }
    ]
}
```

> `~` 运算符本身不落库，约束以「被约束类型引用列表」保留。

多个方法自身类型参数 + 复合类型参数：

```go
// @GET
func (s *Stack[T]) Convert[K comparable, V any](in []T) map[K]V { return nil }
```

```json
{
    "params": [
        { "name": "in", "type": { "kind": "slice", "elem_type": { "name": "T", "kind": "typeparam" } } }
    ],
    "results": [
        {
            "name": "",
            "type": {
                "kind": "map",
                "key_type":  { "name": "K", "kind": "typeparam" },
                "elem_type": { "name": "V", "kind": "typeparam" }
            }
        }
    ],
    "generic": {
        "params": [
            { "name": "K", "constraints": [ { "name": "comparable", "kind": "struct" } ] },
            { "name": "V", "constraints": [ { "name": "any", "kind": "struct" } ] }
        ]
    }
}
```

自由泛型函数与泛型方法走同一套解析：

```go
// @GET
func Filter[T any, R any](in []T, keep func(T) bool) []R { return nil }
```

```json
{
    "name": "Filter",
    "recv": null,
    "params": [
        { "name": "in", "type": { "kind": "slice", "elem_type": { "name": "T", "kind": "typeparam" } } },
        { "name": "keep", "type": { "kind": "func" } }
    ],
    "results": [
        { "name": "", "type": { "kind": "slice", "elem_type": { "name": "R", "kind": "typeparam" } } }
    ],
    "generic": {
        "params": [
            { "name": "T", "constraints": [ { "name": "any", "kind": "struct" } ] },
            { "name": "R", "constraints": [ { "name": "any", "kind": "struct" } ] }
        ]
    }
}
```

### 类型参数标记的边界

- 只有**直接**以类型参数为类型的引用被改写：`V`、`T`、`[]T` 的 `elem_type`、
  `map[K]V` 的 `key_type`/`elem_type`。
- `*V` 保持 `{ "kind": "pointer", "name": "V" }`：指针形状对参数绑定更有价值，不改写。
- 带 `pkg_path` 的引用（如 `demo.TestStruct`）不会被标记。
- 方法自身类型参数与接收器实参同名（Go 允许遮蔽）时按名字合并，属可接受行为。
- **接口方法不允许声明类型参数**（Go 1.27 规格限制，解析器直接报错）。

## Param

参数与返回值共用：

```go
type Param struct {
    Name string
    Type *TypeRef
}
```

```json
[
    { "name": "a", "type": { "name": "*demo.TestStruct", "kind": "pointer" } },
    { "name": "b", "type": { "name": "demo.TestStruct2", "kind": "pointer",
        "generic": { "args": [ { "name": "demo.BaseStruct", "kind": "struct" } ] } } },
    { "name": "c", "type": { "kind": "slice", "elem_type": { "name": "string", "kind": "basic" } } }
]
```

> `...string` 变参在模型里与 `[]string` 同形（都是 `kind: "slice"`），不单独标记。

## TypeRef

```go
type TypeRef struct {
    Name     string
    PkgPath  string
    Kind     TypeKind
    Generic  *GenericArg // 泛型实例化实参，如 Stack[T] 的 [T]
    KeyType  *TypeRef    // map 键
    ElemType *TypeRef    // slice / map / pointer 元素
}
```

`GenericArg`：

```go
type GenericArg struct {
    Args []*TypeRef
}
```

`Query.ResolveTypeRef` 的行为：

| `Kind` | 返回 |
| --- | --- |
| `basic` / `typeparam` / `slice` / `map` / `func` | `nil` |
| `pointer` / `struct` | 按 `Name` 查找 `Type` |

`kind: "typeparam"` 是 Go 1.27 泛型支持新增的取值，语义为「这是一个类型参数」，
因此不参与具名类型解析。

## GenericSpec / GenericParam

```go
type GenericSpec struct {
    Params []*GenericParam
}

type GenericParam struct {
    Name        string
    Constraints []*TypeRef
}
```

```json
"generic": {
    "params": [
        { "name": "T", "constraints": [ { "name": "any", "kind": "struct" } ] }
    ]
}
```

结构体（`Type.Generic`）、自由函数与方法（`Func.Generic`）三者共用同一套解析。
约束表达式支持范围：

| 写法 | `constraints` |
| --- | --- |
| `T any` | `[{name:"any"}]` |
| `T comparable` | `[{name:"comparable"}]` |
| `T ~U` | `[{name:"U"}]`（`~` 本身不落库） |
| `T int \| string` | `[{name:"int"},{name:"string"}]` |
| `T (int \| string)` | `[{name:"int"},{name:"string"}]` |
| `T interface{ ~int \| string }` | `[{name:"int"},{name:"string"}]` |

> 注：约束引用的 `kind` 由 `isBasicType` 决定——`int`/`string` 等真正的内置类型是
> `"basic"`，而 `any` / `comparable` 不在 `isBasicType` 名单里，因此是 `"struct"`
> （含义只是「非内置的裸名字」，不代表它真是结构体）。这是 `parseTypeRef` 的既有行为，
> 本次未改动。

## Var / Const / Enum

```go
type Var struct {
    Name    string
    PkgPath string
    Type    *TypeRef
    Doc     *CommentGroup
}

type Const struct {
    Name    string
    PkgPath string
    Type    *TypeRef
    Value   string
    Doc     *CommentGroup
}

type Enum struct {
    Name    string
    PkgPath string
    Type    *TypeRef
    Values  []*EnumValue
    Doc     *CommentGroup
}

type EnumValue struct {
    Name  string
    Value string
    Doc   *CommentGroup
}
```

```json
{
    "name": "Status",
    "pkg_path": "astp/testdata",
    "kind": "enum",
    "alias_of": { "name": "int", "kind": "basic" },
    "values": [
        { "name": "StatusActive", "value": "iota" },
        { "name": "StatusInactive" },
        { "name": "StatusPending" }
    ]
}
```

## 复杂示例

```go
// PageBase doc1
// doc2
// @Body
type PageBase[T any, E any] struct {
    Page T `json:"page"` // page
    Size E `json:"size"` // page size
}

// Resp doc1
// doc2
// @Body
type Resp[T any, E any] struct {
    PageBase[T, E]
    Name string `json:"name,omitempty"` //name
    A []T `json:"a"`
    B *E `json:"b"`
    d string
}
```

```json
{
    "name": "Resp",
    "pkg_path": "astp/testdata",
    "kind": "struct",
    "fields": [
        {
            "name": "_",
            "type": {
                "name": "PageBase",
                "kind": "struct",
                "generic": { "args": [ { "name": "T", "kind": "struct" }, { "name": "E", "kind": "struct" } ] }
            },
            "embedded": true
        },
        {
            "name": "Name",
            "type": { "name": "string", "kind": "basic" },
            "tag": { "json": "name,omitempty" }
        },
        {
            "name": "A",
            "type": { "kind": "slice", "elem_type": { "name": "T", "kind": "struct" } },
            "tag": { "json": "a" }
        },
        {
            "name": "B",
            "type": { "name": "E", "kind": "pointer" },
            "tag": { "json": "b" }
        }
    ],
    "generic": {
        "params": [
            { "name": "T", "constraints": [ { "name": "any", "kind": "struct" } ] },
            { "name": "E", "constraints": [ { "name": "any", "kind": "struct" } ] }
        ]
    },
    "doc": {
        "list": [ { "text": "Resp doc1" }, { "text": "doc2" }, { "text": "@Body" } ],
        "annotations": [ "Body" ]
    }
}
```

> 注意字段里的 `T`/`E` 仍是 `kind: "struct"`（见上文「Field」一节的说明），
> 与函数/方法签名内的 `kind: "typeparam"` 不同。
